## Interpretation

- `Sxx-Lnnn` is a **source-line locator**, not a new approved `REQ` identifier or independent requirement definition. `-a/-b` suffixes separate multiple clauses sharing one source line. Short snippets below are navigational: click the pinned original source for the complete rule, including surrounding definitions, formulas, tables and exceptions.
- **Mandatory/contract** covers committed features, domain rules, data constraints and required flows. **Mandatory acceptance** denotes a Release 1.0 verification obligation. **Should** denotes explicit SHOULD guidance. **Optional/permission** does not expand the commitment. **Excluded** preserves the Release 1.0 boundary. **Conditional guidance** flags caveats. These classifications are proposals for independent review, not Product Owner approvals.
- Feature/Task/Issue links and owner assignments are **candidate trace edges**, reconciled against actual TODO M00–M09 task descriptions and ARCHITECTURE §6 field ownership. Multi-domain links are not verified interface ownership. An Issue connection is **planned work**, not implemented evidence.
- Verification text is a **planned oracle pointer**, never a test ID or observed pass. No runnable test suite, code, verified CI, deployment or release is evidenced at this revision. `Planned; no source/test run` applies to every row, including §16.
- Teaching outcomes are **curriculum pointers**, not assertions that a learner has achieved the objective. Official course/BNCC applicability remains subject to the teacher's validation.
